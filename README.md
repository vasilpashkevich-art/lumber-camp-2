# Лагерь лесоруба II

Браузерная 2D-игра в духе World of Warcraft: открытый мир по зонам, мобы своего уровня, добыча, прокачка до 50, столица с рынком и мастерами. Вторая ветка «Лагеря лесоруба».

- Играть: https://vasilpashkevich-art.github.io/lumber-camp-2/
- Главная версия — артефакт в Claude, этот репозиторий — копия кода.
- Что решено по игре — `CONCEPT.md`, как устроен код и как работать — `CLAUDE.md`.

## Сборка и проверка
```
npm install
npm run build        # dist/lumber-camp.html и index.html
npm test             # механики, сохранения, автоигрок
node tools/sim.mjs   # баланс: минуты до каждого уровня
```
Прогресс хранится в браузере (`localStorage`, ключи `lumber-camp2-*`), переносится файлом с экрана выбора героя.
